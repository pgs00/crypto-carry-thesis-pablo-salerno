# Evidencia complementaria

El [ZIP complementario](Evidencia_complementaria_Pablo_Salerno.zip) contiene
los insumos y resultados de los análisis añadidos a la tesina.

| Análisis | Resultado |
|---|---|
| Comparadores H1 | MAE: EWMA 6,2990 pb; última tasa 8,7033 pb; media de siete días 6,5764 pb. |
| H3 anual | Oportunidad media por 168 horas: 0; 2,6808; 10,6972; 0; 0 pb en 2022–2026. El último año abarca enero–agosto. |
| Caja a SOFR | Al remunerar 100% del saldo contable libre, CAGR de 4,6853% condicional y 3,7529% incondicional. Con 50%, son 3,2008% y 3,5683%. |

Las carpetas `quant_h1/` y `cash_review/` del ZIP contienen las observaciones
y series de cálculo. La evidencia también incluye estadísticas de basis y
funding y las fuentes de las figuras.

La [metodología](../../docs/methodology.md) define estos ejercicios y sus
supuestos. Se verifican junto con las demás tablas mediante el
[comando único](../../docs/reproduction.md).
