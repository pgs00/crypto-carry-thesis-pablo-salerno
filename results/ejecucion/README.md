# Precio de ejecución y demoras

La referencia OHLC4 cambia el P&L frente a BASE en +7,33 USDT para la
condicional y −22,63 USDT para la incondicional. Las demoras alteran trayectorias
completas y su efecto en la rentabilidad no es monótono.

Demorar un minuto todas las órdenes cliente es favorable a H2 en la muestra
completa: Sharpe 4,74 condicional frente a 4,21 incondicional, con CAGR
condicional positivo. Las demás variantes completas son no favorables.
